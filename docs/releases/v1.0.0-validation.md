# anmitsu 1.0.0 ソースの検証結果

対象: 書き出したソースの複製（元のコミット `0283d4e`、versionName 1.0.0・versionCode 1）。開発者の環境で、既存のツール・キャッシュと既存の辞書・AIのファイルを使って実行しました。公開前の記録で、リポジトリとリリースはまだ公開していません。

**まとめ: コンパイル・lint・パッケージ化は完了しました。テストは2つの実行でそれぞれ1件失敗しており、原因は未解決です。** すべてのテストが合格したとは言えません。

## 1. テスト

| 対象 | 結果 |
|---|---|
| Python（`python -m unittest discover tests`） | 56件合格 |
| `:core:test` | 118件合格 |
| `:oss-converter:test` | 105件合格 |
| `:app:testDebugUnitTest` | 521件中 519件合格・**1件失敗**・1件スキップ |
| `:app:testReleaseUnitTest` | 521件中 519件合格・**1件失敗**・1件スキップ |

失敗したテスト（どちらも `InputUiTest`）:

- debug: `backspaceHonoursACaretTappedInsideTheSelectedSegment`（1103行）。期待 `[あしは|, 雨]`、実際 `[明日|, 雨]`。このテストだけを実行し直すと合格しました（1件中1件）。
- release: `backspaceOnTheFirstSegmentDeletesItsLastKanaThenContinuesBackwards`（1013行）。期待 `[あし|, 、, 雨]`、実際 `[朝|, 、, 雨]`。実行し直していません。

**未解決（公開前に調べること）。** 原因は確かめていません。テストのコードを読んで分かったのは次の2点だけです。

- 待ち合わせの補助関数 `pumpUntil` は、条件がそろわないまま 300回×10ms が過ぎても失敗せずに戻ります。
- 1013行のテストのコメントには「あし: no word」とありますが、別のテストは、試験用の辞書が「あし」を「朝」に直すことを前提にしています。

どちらも、テストの期待値か待ち方の問題を疑わせますが、根拠にはなりません。利用者に見える不具合かどうかも確かめていません。アプリとテストは変えていません。

## 2. ビルド・lint・パッケージ化

- テストの失敗のあとも `--continue` で `assembleRelease` と `lintRelease` を実行し、両方のタスクが完了しました。Gradle 全体の終了コードは、テストの失敗のため 1 です。
- lint: エラー 0、警告 3（`NewerVersionAvailable`、`UnsafeDynamicallyLoadedCode`、`ClickableViewAccessibility`）。
- `scripts/package-android.ps1 -Version 1.0.0 -Release -RequireOss -RequireZenz`: 終了コード 0。できたのは**署名していない**APKです（SHA-256 `da7457e1ab2dc91965a7569ce14a6c5f3806b39eafa910536843fded0ae8e2da`）。apksigner が署名がないと表示するのは想定どおりです。公式APK（`2f454398…`、署名済み）とは別のファイルです。公式APKは変えていません。

## 3. 公式APKとの比較

`META-INF/` を除くすべての項目を比べました。

- 37項目はバイト単位で同じ（dex、リソース、辞書、モデル、ネイティブライブラリを含む）。
- 4項目は改行（CRLF と LF）だけが違う: `assets/lexicon.tsv`、`assets/licenses/Kotlin-LICENSE.txt`、`assets/licenses/Kotlin-NOTICE.txt`、`assets/licenses/THIRD-PARTY.md`。
- 片方にしかない項目はない。

**これはビルドの再現性の証明ではありません。** APK全体はバイト単位で同じではなく、次の条件での結果です。

- ネイティブライブラリ（`libastra_zenz.so`）は新しくビルドせず、公式APKから取り出してロックのハッシュと照合したものを使いました。
- ツール・Gradle のキャッシュ・辞書・モデルは、開発者の環境にすでにあったものです。依存関係を何もない環境から取得し直してはいません。

## 4. 書き出し

- 上のテスト・ビルドは、最初の書き出し（マニフェストを含む259ファイル）の複製で行いました。その書き出しでは、ハッシュはすべて一致、拒否したパス・リンク・ジャンクションはなし、Markdown の相対リンクの切れはなし。
- テスト・ビルドの前後で、入力にした258ファイルのハッシュは変わっていません。
- その後に加えた・直した文書（この文書を含む）は文書だけで、テスト・ビルドから読まれないため、テストは実行し直していません。
