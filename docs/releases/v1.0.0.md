## 0.1.x の試験版からの変更

### 新しいパッケージ

- パッケージ名を `dev.astra.ime.trial` から `io.github.tama_no_holiday.anmitsu` に変え、versionCode を 1 から数え直しました。
- そのため試験版の**更新にはならず**、別のアプリとして並びます。設定・学習・登録した単語・テーマは引き継がれません。試験版も表示名が `anmitsu` なので、キーボードの一覧に同じ名前が2つ並ぶことがあります。不要になった試験版は手動でアンインストールしてください。

### リリースビルド

- 署名しないリリースビルドを追加しました。公式APKは、このビルドを開発者の鍵で署名したものです。
- R8（コードの縮小・難読化）は使っていません。ネイティブ呼び出しとメモリマップの経路で確かめていないためです。
- これまでデバッグビルドだけで有効だった辞書・AI・補正の制限をなくし、どのビルドでも同じ機能が動きます。

### AIの読み込み方

- AIのライブラリ（`libastra_zenz.so`、arm64-v8a）を APK の `lib/` ではなく `assets/` に入れました。これで ABI を問わずにAPKを導入できます。
- 読み込む前に CPU を確かめます（`/proc/self/auxv` の AT_HWCAP、なければ `/proc/cpuinfo` の全行）。64ビットの arm64 プロセスで必要な機能がすべてそろう場合だけ、ライブラリとモデルをアプリ専用の領域へコピーし、ハッシュを確かめ、読み取り専用にしてから読み込みます。
- 条件を満たさない端末、判定できない端末では何もコピー・読み込みせず、通常の辞書変換で動きます。設定のAIスイッチは表示されますが効果はありません。

### 試験版までに入った主な機能

12キーのフリック入力、英字（12キー／QWERTY）、数字、記号・絵文字の一覧と履歴、ライブ変換、文節の選び直し、候補一覧、打ち間違いの補正候補、Mozc と Mozc-UT 由来の辞書（約284万件）、端末内のAI（zenz-v3.2 xsmall）による順位付け、確定済みの前の文を使った順位付け、学習と単語登録、クリップボードの貼り付け表示、テーマ5種。

## ソース公開に合わせた変更（アプリには影響しません）

- あんみつ自身のコードのライセンスを MIT にしました（[LICENSE](../../LICENSE)）。第三者の部品・辞書・モデルは元のライセンスのままです。
- README、参加のしかた、脆弱性の報告方法、issue とプルリクエストのテンプレートを整えました。
- アプリのコード・版・同梱するファイル・公式APKは変えていません。

## 検証

- 1.0.0 のソースで、辞書・AIを入れた全テストを実行したとき、debug・release の UIテストでそれぞれ1件が失敗しました（別のテスト）。原因は分かっておらず、利用者に見える不具合かどうかも確かめていません。
- その後、辞書・AIを入れない（試験用の辞書だけの）構成で、debug のテスト・lint・デバッグビルドが通りました。release のテストは実行し直していません。これは上の失敗が解決したことを示すものではありません。
- 複数の機種・OS版での動作、実際のCPUでのAI判定、性能と電池消費、ビルドの再現性は確かめていません。

詳細は [v1.0.0-validation.md](v1.0.0-validation.md) にあります。
