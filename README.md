# あんみつ（anmitsu）

あんみつは、Android向けの日本語キーボード（IME）です。変換はすべて端末内で行い、アプリはネットワーク権限を持ちません。アプリの表示名は `anmitsu` です。

> この文書は 1.0.0 のソース公開に向けた下書きです。公開リポジトリの名前は `anmitsu` に決まっており、`https://github.com/tama-no-holiday/anmitsu` に置き、APKをその GitHub Releases で配布する予定です。リポジトリの作成・公開とリリースの公開はまだ済んでいません。ライセンスは未決定です（下の「未確定の事項」）。

## できること

- 12キーのフリック入力、英字（12キー／QWERTY）、数字、記号と絵文字の一覧（記号・絵文字の履歴つき）
- ライブ変換、文節を選んでの選び直し、候補一覧
- フリックの打ち間違いを直した補正候補（入力どおりの候補は常に残ります）
- 学習（既定でオン、オフと消去が可能）と単語登録
- クリップボードの文字を候補欄に出して貼り付け
- テーマ 5 種

### 辞書とAI

- 辞書: Mozc の OSS 辞書データと Mozc-UT 辞書の語彙（合計約284万件）を、メモリマップして使います。辞書を読めないときは、小さな手作りの内蔵辞書で変換します。
- AI: 端末内の小さな言語モデル zenz-v3.2 xsmall（約21MB）が、辞書の候補の順番を判定します。このプロジェクトではモデルの学習・追加学習をしていません。
- AIは、64ビットの arm64-v8a プロセスで、CPUが必要な機能（`fp`・`asimd`・`crc32`・`atomics`・`fphp`・`asimdhp`・`asimdrdm`・`asimddp`）をすべて報告する場合だけ使います。条件を満たさない端末（x86・x86_64、32ビットARM、ARMv8.0だけのCPUなど）や、判定に必要な情報を読めない端末では、AIのネイティブコードを一切読み込まず、辞書だけで変換します。設定のAIスイッチは表示されますが、その場合は効果がありません。
- AIを使う端末では、初回にモデルとライブラリをアプリ専用の領域へコピーし、ハッシュを確かめてから読み込みます。APKは約95MBです。

## 導入

1. APKを導入し、アプリ一覧から「anmitsu」を開きます。
2. 「1. キーボードの設定を開いて有効にする」から、システムの設定で anmitsu をオンにします。
3. 「2. このキーボードに切り替える」で anmitsu を選びます。元のキーボード（Gboardなど）は残しておいてください。

### 有効にするときの警告について

手順2で、Androidは「この入力方法を使うと、パスワードやクレジットカード番号などの個人情報を含め、入力する文字がすべて収集される可能性がある」という趣旨の警告を出します（文面はAndroidの版によって違います）。これは、システム標準ではないキーボードを有効にするときに、Androidがどのキーボードに対しても出す警告です。あんみつの動作を調べた結果ではありません。

キーボードは仕組みの上で入力した文字に触れます。あんみつがそれをどう扱うかは [PRIVACY.md](PRIVACY.md) に、ソースコードの該当箇所とあわせて書いています。要点は次のとおりです。

- ネットワーク権限がなく、入力した文字を送信しません。
- 保存するのは、学習がオンのときの確定した変換、記号・絵文字の履歴、登録した単語、設定だけです。どれもアプリ専用の領域にあり、バックアップや機種変更の転送の対象から外しています。
- パスワード欄では変換・学習・クリップボードの表示をせず、そのまま入力します。

### 0.1.x の試験版を使っていた場合

1.0.0 はパッケージ名が変わったため、0.1.x の試験版（`dev.astra.ime.trial`）の**更新にはなりません**。

- 両方が別のアプリとして並びます。設定・学習した変換・登録した単語・テーマは引き継がれません。
- 0.1.25 以降の試験版も表示名が `anmitsu` なので、キーボードの一覧に同じ名前が2つ並ぶことがあります。区別しにくい場合は、不要になった試験版を手動でアンインストールしてください（試験版のデータは消えます）。
- 署名の違うAPKは上書きできません。同じパッケージ名で別の鍵のAPK（自分でビルドしたものなど）に入れ替えるには、アンインストールが必要で、そのときデータは消えます。

## 既知の制限

- TalkBackで個々のキーや記号の一覧を選べません。
- 確定済みの前の文を使った順位付けは、入力欄に前の文を問い合わせます。最初のキーで最大0.1秒待つことがあります（[PRIVACY.md](PRIVACY.md)）。
- クラッシュの報告機能はありません。
