# あんみつ（anmitsu）

あんみつは、Android向けの日本語キーボード（IME）です。変換はすべて端末内で行い、アプリは権限を一つも要求しません（`INTERNET` もありません）。

| 項目 | 値 |
|---|---|
| バージョン | 1.0.0（versionCode 1） |
| パッケージ名 | `io.github.tama_no_holiday.anmitsu` |
| 対応OS | Android 8.0（API 26）以上 |
| 権限 | なし |

## 特徴

- 12キーのフリック入力、英字（12キー／QWERTY）、数字、記号・顔文字・絵文字の一覧と履歴
- ライブ変換、文節を選んでの選び直し、候補一覧
- フリックの打ち間違いを直した補正候補（入力どおりの候補は常に残ります）
- Mozc と Mozc-UT 由来の辞書（約284万件）
- 端末内の小さな言語モデル zenz-v3.2 xsmall による候補の順位付け（対応するCPUだけ、下記）
- 学習（オフと消去が可能）、単語登録、クリップボードの貼り付け表示、テーマ5種

## 端末内処理とプライバシー

- 入力した文字を送信しません。分析・広告・クラッシュ報告の仕組みはありません。
- 保存するのは、学習がオンのときの確定した変換、記号・絵文字の履歴、登録した単語、設定だけです。アプリ専用の領域に置き、バックアップと機種変更の転送の対象から外しています。
- パスワード欄では変換・学習・クリップボードの表示をしません。

詳しくは [PRIVACY.md](PRIVACY.md) にあります。

## AIを使う条件

AIは、64ビットの arm64-v8a プロセスで、CPUが必要な機能（`fp`・`asimd`・`crc32`・`atomics`・`fphp`・`asimdhp`・`asimdrdm`・`asimddp`）をすべて報告する場合だけ使います。

条件を満たさない端末（x86・x86_64、32ビットARM、ARMv8.0だけのCPUなど）や判定できない端末では、AIのネイティブコードを読み込まず、**通常の辞書変換**で動きます。設定のAIスイッチは表示されますが、効果はありません。どの機種が条件を満たすかの一覧はありません。

## 導入と設定

1. APKを導入し、アプリ一覧から「anmitsu」を開きます。
2. 「1. キーボードの設定を開いて有効にする」から、システムの設定で anmitsu をオンにします。
3. 「2. このキーボードに切り替える」で anmitsu を選びます。元のキーボードは残しておいてください。

手順2で Android は「入力する文字が収集される可能性がある」という趣旨の警告を出すことがあります。これは、追加したキーボードを有効にするときに Android が標準で出す警告で、表示の有無や文言は端末・OSの版によって違います。この警告は、そのキーボードが実際に文字を収集することを示すものではありません。あんみつの扱いは [PRIVACY.md](PRIVACY.md) を見てください。

同じ画面の「設定」で、ライブ変換、打ち間違いの補正候補、AI、確定済みの前の文の利用、英字・数字のキー配列、キーボードの色、学習と単語登録を変えられます。

### 0.1.x の試験版について

1.0.0 は試験版（`dev.astra.ime.trial`）とは別のアプリで、更新にはなりません。設定・学習・登録した単語は引き継がれず、キーボードの一覧に同じ名前が2つ並ぶことがあります。不要な試験版は手動でアンインストールしてください（試験版のデータは消えます）。

## 既知の制限

- TalkBack で個々のキーや記号の一覧を選べません。
- 確定済みの前の文を使う設定では、最初のキーで最大0.1秒待つことがあります。
- 確認した端末・OS版は限られています。性能・電池消費は測っていません。
- 公開中の署名済み 1.0.0 APK のライセンス表記には、古い記述（1.0.0 で変わった点）と不足（AIモデルの現在の表示 CC BY-SA 4.0、llamafile sgemm の表記）があります。ソースでは直しましたが、直したソースから作った APK はまだありません（[THIRD-PARTY.md](THIRD-PARTY.md)）。
- クラッシュの報告機能はありません。
